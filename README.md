# ML From Scratch

A hands-on repository where classic machine learning and deep learning algorithms are implemented **from scratch** using only Python and NumPy/PyTorch basics, with minimal external abstraction.

This repository is built to strengthen:
- ML fundamentals
- interview preparation
- mathematical intuition
- implementation clarity
- debugging ability

It is designed as a learning-first repo, not a production ML library.

---

## Why This Repository Exists

Most people can train models using `scikit-learn` or `transformers`, but far fewer can explain and implement the core mechanics behind them.

This repository helps build that depth by implementing algorithms manually, step by step.

It supports:
- **AI/ML interview preparation**
- **understanding model internals**
- **revising core ML concepts**
- **showcasing strong foundations publicly on GitHub**

---

## What Is Implemented

### Classical Machine Learning
- Linear Regression
- Logistic Regression
- K-Means Clustering

- K-Nearest Neighbors *(optional if added later)*

### Deep Learning Foundations

### Transformer / LLM Foundations
